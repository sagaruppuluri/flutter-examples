# Prerequisites

1. MySQL Installation 
    
    Download MySQL Community Server based on your OS and install 

    https://dev.mysql.com/downloads/mysql/

2. NodeJS Installation 

    Download Nodejs and install based on your OS version.

    https://nodejs.org/en/download


3. Flutter setup 

    Download flutter 3.32.8 from the https://docs.flutter.dev/install/archive based on your operating system 
    
    Below example lists out basic steps needed for Windows OS.

    Extract the zip file to the desired folder 

    e.g. c:\software 

    Locate the flutter bin directory e.g. c:\software\flutter\bin 

    Add this directory to the system variable path.
    e.g. 1. edit system evironment 
         2. Environment variables
         3. System variables 
         4. choose path and edit 
         5. add new 
         6. paste bin directory to the path. 
            e.g. c:\software\flutter\bin

    Once done you can use flutter --version to look at the version and it will also complete the flutter initial setup.

    Open command prompt 
        c:\> flutter --version             

4. Install VSCode ( https://code.visualstudio.com/ ) , choose extensions table and search for flutter and install.
   Restart VSCode.

5. Open the MiniProject in the VSCode and follow readme file.
